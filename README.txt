MARIA BLANDZI — DIGITAL PORTFOLIO

Files:
- index.html: the portfolio website
- CV-Maria-Blandzi.pdf: your CV linked from the page

FASTEST WAY TO PUBLISH (no GitHub required):
1. Open https://app.netlify.com/drop in your browser.
2. Drag the whole folder named "maria-portfolio" onto the page (or unzip this package first, then drag the folder).
3. Netlify will publish it and give you a public URL.
4. Open that URL on your phone and test the CV link.
5. Write that exact URL to your NFC tag as a URL/URI record (not plain text).
6. Make a QR code pointing to the same URL as a backup.

You can rename the site in Netlify after publishing. Keep the CV PDF in the same folder as index.html so the CV buttons continue to work.

Before sharing widely, consider whether you want your phone number / social links on the public page. This first version intentionally includes only the email address already present in your CV.
